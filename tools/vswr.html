How to use it

The first panel converts. Type into any one of the six boxes and the other five follow; the box you typed in is left alone. The second panel starts from a load impedance R + jX and a reference impedance, usually 50 Ω, and works out the complex reflection coefficient and everything that follows from it.

The equations

Every quantity here depends only on the magnitude of the reflection coefficient Γ, the ratio of the reflected to the incident voltage wave at the load:

Γ = (ZL − Z0) / (ZL + Z0) VSWR = (1 + |Γ|) / (1 − |Γ|) |Γ| = (VSWR − 1) / (VSWR + 1) Return loss = −20·log10|Γ| dB S11 = 20·log10|Γ| dB Reflected power = |Γ|2 Mismatch loss = −10·log10(1 − |Γ|2) dB

The angle of Γ matters for matching, because it tells you which way to move the impedance, but VSWR and return loss throw it away. Two very different loads, one capacitive and one inductive, can have the same VSWR.

Worked example. A load of 32 − j18 Ω on a 50 Ω line: ZL − Z0 = −18 − j18 and ZL + Z0 = 82 − j18, so Γ = −0.163 − j0.255, or 0.303 at −122.6°. The VSWR is 1.303/0.697 = 1.87:1, the return loss is 10.36 dB, 9.19% of the power is reflected and the mismatch loss is 0.419 dB. These are the defaults in the second panel.

Sign conventions

Return loss is a loss, so it is a positive number of decibels: a good match has a high return loss, such as 20 dB. S11 is a ratio expressed in decibels, so for a passive load it is zero or negative: the same match is S11 = −20 dB. A network analyser plots S11, which is why you will often hear "a return loss of −20 dB". The meaning is clear, but strictly the sign is wrong. This calculator expects return loss as a positive number and shows S11 separately.

A perfect match has |Γ| = 0, a VSWR of exactly 1:1 and an infinite return loss. In practice the analyser's calibration and the connectors' repeatability set a floor on how good a match you can measure, so very high return loss figures mean little. Total reflection, from an open, a short or a pure reactance, has |Γ| = 1, an infinite VSWR and a return loss of 0 dB.

Mismatch loss assumes the source is matched to Z0. If both ends are mismatched, the reflections bounce between them and the power delivered can be higher or lower than the mismatch loss suggests, by up to 20·log10(1 ± |ΓS|·|ΓL|) dB. Two 1.5:1 ends give about +0.34 dB to −0.35 dB.

Why a 1.5:1 antenna spec matters

A VSWR of 1.5:1 reflects 4% of the power and costs 0.18 dB. In a link budget that is close to nothing: losing 6 dB halves free-space range, and 0.18 dB changes it by about 2%. Even 2:1 costs only half a decibel. So why do antenna datasheets and RF specifications insist on 1.5:1 or 2:1?

  • It is a limit across a band. An antenna that is 1.5:1 at the centre frequency on its evaluation board can be much worse at the band edges, and worse again once it is inside a plastic enclosure, near a battery or in someone's hand. A tight spec leaves room for that.
  • The amplifier sees the mismatch. Power amplifiers are designed and characterised into a 50 Ω load. A poor match changes the load the transistor sees, which can reduce output power and efficiency, raise harmonics and, at high power, stress the device. Amplifier datasheets often state a load VSWR the part will survive.
  • Filters assume 50 Ω. A filter, duplexer or matching network designed for 50 Ω terminations ripples and shifts when one end is not 50 Ω.
  • Cable hides a bad match. The reflected wave crosses the cable twice, so the return loss you measure at the far end of a lossy cable is the antenna's return loss plus twice the cable loss. A 1.5:1 antenna behind 3 dB of cable measures about 1.22:1. Measure at the antenna's own connector, or calibrate out the cable.

Accuracy and limits

The conversions are exact definitions, so the only error is rounding in the display. The reflection coefficient assumes a real reference impedance, as on a lossless line. With a complex reference, such as a conjugate match to an amplifier, use the power-wave reflection coefficient instead; the matching network designer does. VSWR describes a standing wave on a line. For a component with no line attached, return loss or |Γ| says the same thing more directly.
